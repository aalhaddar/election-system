## المتطلبات الأساسية

- **Node.js** v18+

- اتصال شبكة محلية (للاستخدام في قاعة الانتخابات)

## تحميل الكود

### عبر GitHub
```bash
git clone https://github.com/aalhaddar/election-system.git
cd election-system
```

### عبر ملف مضغوط (بدون GitHub)
```bash
# على الجهاز المصدر: إنشاء ملف مضغوط
Compress-Archive -Path "C:\path\to\project\*" -DestinationPath "election-system.zip" -Exclude "node_modules", "server\node_modules", "dist", "server\prisma\dev.db"

# انسخ الملف إلى الخادم الجديد (USB / شبكة) ثم فك الضغط
```

## التثبيت والإعداد

### 1. تثبيت الاعتماديات

```bash
# تثبيت اعتماديات الواجهة الأمامية
cd election-management-system
npm install

# تثبيت اعتماديات الخادم
cd server
npm install
cd ..
```

### 2. إعداد قاعدة البيانات

```bash
cd server
npx prisma db push
npx prisma generate
cd ..
```

### 3. بذر البيانات الافتراضية (اختياري)

```bash
cd server
node seed.js
cd ..
```

> الحساب الإداري الافتراضي: `admin` / `admin`

### 4. تشغيل النظام

```bash
# تشغيل الخادم (Express :3001)
cd server && node index.js

# تشغيل الواجهة (Vite :5173) — في نافذة أخرى
npm run dev
```

ثم افتح المتصفح على: `http://localhost:5173`

## نموذج قاعدة البيانات

```
User (مستخدم النظام)
├── id, username (فريد), passwordHash
├── station (null=ADMIN, CHECK_IN, KIOSK)
└── isActive (true/false)

Voter (الناخب)
├── id, personalId (فريد، 9 أرقام), name
├── membershipType (FULL/INCOMPLETE)
└── status (NOT_VOTED / IN_QUEUE / VOTED)

Candidate (المرشح)
├── id, personalId (فريد), formNumber, name
├── qualifications, jobTitle, workplace
├── pictureUrl (رابط أو Base64)
└── positionId → Position

Position (المنصب)
├── id, title, maxSelections
└── candidates → Candidate[]

Vote (الصوت)
├── voterId → Voter
├── positionId → Position
├── candidateId → Candidate
└── @@unique([voterId, positionId, candidateId])

ElectionSettings (إعدادات)
└── isVotingOpen (مفتوح/مغلق)

Organization (المؤسسة)
├── name, electionTitle, electionDate
└── logoUrl (شعار المؤسسة)

AuditLog (سجل التدقيق)
├── action (CREATE/UPDATE/DELETE/CHECK_IN/VOTE)
├── entity, entityId, details
├── userId, station, username
└── createdAt
```

## الأمان

- **JWT**: توقيع التوكن بكلمة سرية (`JWT_SECRET`) في `.env`.
- **كلمات المرور**: مشفرة باستخدام bcrypt (10 rounds).
- **الصلاحيات**: كل نقطة API تتحقق من صلاحية المستخدم عبر `verifyToken` و `requireStation()`.
- **التحقق من المحطات**: مستخدمي المحطات لديهم `isActive` يمكن تعطيلهم دون حذف.
- **سجل التدقيق**: جميع العمليات (إضافة، تعديل، حذف، تصويت، تحقق) تُسجل تلقائياً.
- **التحقق من صحة الإدخال**: أرقام شخصية بحد أقصى 9 أرقام مع منع الأحرف غير الرقمية.

## استكشاف الأخطاء

**الخادم لا يعمل:**
```bash
cd server
node index.js
# تأكد من عدم وجود عملية أخرى على المنفذ 3001
```

**الواجهة لا تتصل بالخادم:**
- تأكد من تشغيل الخادم على `http://localhost:3001`
- تحقق من إعدادات الـ proxy في `vite.config.js`

**البيانات العربية لا تظهر بشكل صحيح:**
- كل البيانات مخزنة بترميز UTF-8
- تأكد من استخدام `[System.Console]::OutputEncoding = [System.Text.Encoding]::UTF8` في PowerShell للاختبار

**خطأ Prisma:**
```bash
cd server
npx prisma generate
npx prisma db push --accept-data-loss
```

## التطوير والإضافة

### إضافة صفحة جديدة
1. أنشئ ملف في `src/pages/`
2. أضف المسار في `src/App.jsx`
3. استخدم `ProtectedRoute` مع `requiredStation` المناسب
4. أضف نقطة API في `server/index.js`

### إضافة نوع تقرير جديد
1. أضف خياراً جديداً في مصفوفة `REPORT_OPTIONS` في `AdminDashboard.jsx`
2. أضف `case` جديد في `GET /api/reports/:id` في `server/index.js`
